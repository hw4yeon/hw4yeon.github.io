### **문제 설명**

**쿠키로 인증 상태를 관리하는 간단한 로그인 서비스입니다.
admin 계정으로 로그인에 성공하면 플래그를 획득할 수 있습니다.
플래그 형식은 DH{...} 입니다.**

### Cookie

브라우저에 사용자 정보를 저장하기 위해 사용하는 것

- 사용자가 로그인을 성공하면 서버는 브라우저에 Cookie를 저장함
- 이후 사용자가 웹사이트에 다시 접속하면 브라우저는 저장된 Cookie를 서버에 자동으로 전달함
- 서버는 전달받은 Cookie를 통해 사용자가 누구인지 확인하고 로그인 상태를 유지

#### Cookie 확인 방법

Chrome 브라우저 기준으로 개발자 도구(F12)를 열고 Application -> Cookies 메뉴에서 확인할 수 있음

#### Cookie 사용 예시

Flask에서 Cookie 값을 가져오는 코드

```c
username = request.cookies.get('username', None)
```

| 코드 | 의미 |
| --- | --- |
| request | 사용자의 요청 정보 |
| cookies | 브라우저가 전달한 cookie |
| get('username') | username cookie 값 조회 |
| None | Cookie가 없을 경우 반환값 |
